01 · Introduction

Introduction to Exceptions

An exception is an unwanted event that occurs during program execution and interrupts the normal flow of instructions. Java provides an exception-handling mechanism so programs can detect and handle such situations gracefully.

Why exceptions occur

  • Dividing a number by zero
  • Accessing an invalid array index
  • Using a null reference
  • Reading a missing file

Benefits

  • Prevents sudden program termination
  • Separates error-handling code
  • Improves program reliability
  • Helps developers diagnose problems
02 · Key Term

Throwable Class

Throwable is the root class of Java's error and exception hierarchy. Objects that can be thrown by the Java runtime or by a program are derived from this class.

getMessage()printStackTrace()toString()

Its two major branches are Error and Exception.

Diagram Explanation

Throwable is at the top. It branches into Error and Exception. Error represents serious conditions that applications normally do not recover from. Exception represents conditions that application code can often handle. RuntimeException is an important subclass of Exception and contains many unchecked exceptions.

05 · Classification

Checked and Unchecked Exceptions

Checked Exceptions

Checked exceptions are checked by the compiler. A method generally must handle them with try-catch or declare them using throws.

Examples: IOException, SQLException, FileNotFoundException.

Unchecked Exceptions

Unchecked exceptions are subclasses of RuntimeException. The compiler does not require explicit handling.

Examples: NullPointerException, ArithmeticException, ArrayIndexOutOfBoundsException.

06 · Practical Examples

Java Examples

ArithmeticException

public class Demo {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero.");
        }
    }
}

ArrayIndexOutOfBoundsException

public class Demo {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30};

        try {
            System.out.println(numbers[5]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid array index.");
        }
    }
}

Checked Exception

import java.io.*;

public class Demo {
    public static void main(String[] args) {
        try {
            FileReader f = new FileReader("data.txt");
        } catch (FileNotFoundException e) {
            System.out.println("File not found.");
        }
    }
}

finally Block

try {
    System.out.println("Processing...");
} catch (Exception e) {
    System.out.println("Exception handled");
} finally {
    System.out.println("This block executes.");
}
07 · Summary

Conclusion

Java's exception hierarchy provides a structured way to represent and handle abnormal conditions. Understanding Throwable, Error, Exception, RuntimeException, checked exceptions, and unchecked exceptions helps developers write safer and more maintainable programs.

Using try, catch, finally, throw, and throws appropriately allows programs to respond to exceptional situations without unnecessarily disrupting normal execution.
